# Findbar v1.0.0

> Address-bar keyword shortcuts for Safari, on iPhone, iPad, and Mac.

**[Get it on the App Store →](https://apps.apple.com/app/id6773464299)**  ·  **[Marketing site](https://corvusdevs.github.io/Findbar-For-Safari/)**

---

Type `g swiftui` in Safari's address bar to jump straight to Google's results. `gh corvusdevs/findbar-for-safari` opens that repo on GitHub. `w pacific ocean` lands on the Wikipedia article. Thirty-plus short triggers ship built in across Search, References & docs, Code, Social, Media, Shopping & maps, Package managers, and Utilities & stores. Add your own, edit anything, reset whenever.

## What's in it

**Keyword shortcuts**
- 30+ built-in triggers across 8 groups, all editable.
- Per-keyword aliases (`d, ddg, duck` → DuckDuckGo).
- Regex keywords with `$1` / `$2` capture groups.
- `%s` placeholder + per-keyword default arg.
- Multi-tab chaining: `!g foo !w bar` opens two tabs.

**URL rewriting**
- 10 curated rules across two groups (tracking cleanup, frontend replacements). All off by default.
- Reddit → old.reddit, Twitter/X → Nitter, YouTube → Piped, and more.
- Add your own regex rewrites.

**Polish**
- iOS-native settings layout (grouped cards, iOS pill toggles, picker sheets).
- Auto / Light / Dark theme picker.
- DNR fast-path for built-in shortcuts, no visible delay before redirect.

**Privacy**
- 100% on-device. No account, no telemetry, no cloud sync.

**Localization**
- 33 languages, with iOS Settings vocabulary parity (Spanish "Claro" / French "Clair" match what iOS Settings shows).
- In-app language picker independent of system locale.
