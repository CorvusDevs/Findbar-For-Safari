Findbar
for Safari

在 Safari 的網址列輸入關鍵字，即可跳轉至任何網站。內建三十個快速鍵，可一次開啟多個網站，支援正規表達式關鍵字與可選的網址轉換，所有功能皆可編輯且完全在裝置上運行。這是專為 macOS、iOS 和 iPadOS 打造的原生 Safari 延伸功能。

功能

進化的網址列

30 內建關鍵字

g、d、b 用於搜尋；w、mdn、ad 用於參考資料；gh、so 用於程式碼；y、spo、n 用於媒體；npm、cargo、pip、brew 用於套件管理器等。

編輯每個關鍵字

可修改觸發器、URL 範本、預設 URL 或別名，並新增自訂項目；支援將項目移至包含 20 個條目的回收站進行軟刪除以備復原。

開啟多個網站

輸入「!g foo !w bar」可在目前分頁開啟 Google，並在新分頁開啟 Wikipedia，分隔符號可自訂。

正規表達式關鍵字

透過單一鍵入即可實現模式配對的快速鍵（例如 gh/(\S+)/(\S+) → github.com/$1/$2），用於問題、PR 及倉庫導航。

URL 重新寫入

精心策劃的規則可將 Twitter 重定向至 Nitter、Reddit 重定向至 old.reddit、YouTube 重定向至 Piped 及其他注重隱私的前端，所有規則均可切換並編輯。

即時驗證

輸入時會即時顯示友善的錯誤提示，例如缺少 URL 協議、無效的正則表達式、捕獲組不匹配或觸發器衝突。

33 種語言

內建支援旗幟圖示與原生語言名稱的語言選擇器，預設使用您的系統區域設定，並可隨時從設定頁面右上角切換。

零閃轉發

內建關鍵字會編譯為 Safari 的 declarativeNetRequest 規則，在重新導向觸發前不會有可見閃爍，提供最快的路徑。

隱私優先

無需帳號、無需雲端同步、無需分析，您的關鍵字清單完全儲存在本機，Findbar 不會收集任何資料。

即時關鍵字搜尋

編輯器中的篩選列會隨著您輸入而縮小清單。只需兩下按鍵即可找到您 100+ 個快速鍵中的任何一個。

50+ 服務圖示

內建熱門服務的 favicon 選擇器，或貼上任何網址以使用自訂圖示。圖示會與您的關鍵字清單同步。

三種主題

自動、淺色或深色。自動模式會跟隨您的系統設定。您的選擇會持續保留，並在每次啟動及其他 Apple 裝置上使用。

通用應用程式

一次購買即可在 Mac、iPad 和 iPhone 上使用。無需付費 Pro 版本，無需訂閱，也無內購項目。

即時開 / 關

單一主控開關即可一鍵停用 Findbar，無需解除安裝。非常適合共用 Mac 或在工作中暫停使用。

針對行動裝置優化

在 iPhone 上，編輯器會切換為適合單拇指操作的層級式佈局。支援安全區域的全幅頁面，以及 44pt 的觸控目標。

更新內容

首次更新後重新啟動時，歡迎頁面會清楚顯示所有變更。設定項目會以「NEW」標籤標示新功能。

運作方式

加速地址列三步驟

1

從 App Store 安裝

從 App Store 下載 Findbar，透過家庭共享，一次購買即可在 Mac、iPhone 和 iPad 上使用。

2

Safari 中啟用

開啟 Safari 設定 → 延伸功能 → 啟用「Findbar」，並授予其請求的權限。

3

輸入關鍵字

在 Safari 的位址列輸入 g 加上您的搜尋內容，然後按 Enter 即可。您隨時可在設定頁面編輯並新增關鍵字。

為何Findbar

專為 Safari 打造

非 Chrome 移植版

Findbar使用 Safari 原生 API（declarativeNetRequest、webNavigation 和 storage）打造，專為 Safari 量身打造，而非 Chrome 全域Findbar API 的多重實現（因 Safari 不支援該 API）。

零資料收集

無需帳號、無需遙測、無需雲端。您的關鍵字清單、重寫規則與偏好設定完全儲存在本機，Findbar 絕不會向遠端伺服器匯報。

完全本地化

已翻譯為 32 種非英語系語言（包括西班牙語、日語、阿拉伯語、德語、法語等），並可在應用程式內切換，獨立於系統語言。

需要 macOS 14.0（Sonoma）或更高版本，或 iOS/iPadOS 17.0 或更高版本，並與 Safari 17+ 相容。
